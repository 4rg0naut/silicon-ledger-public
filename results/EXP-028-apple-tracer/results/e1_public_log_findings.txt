EXP-028 E1 — public os-log + cache-plan fingerprints for lane attribution (unprivileged)

Harness: harness/p28_e1_signpost.sh (arms: default|neuralEngine|gpu|cpuOnly) +
harness/p28_capture.sh (generic stream wrapper). Raw: raw/p28_e1_smoke/, raw/p28_e1_anec/.

1. LANE FINGERPRINT (in-process, no sudo, no entitlement):
   - GPU-delegate arms emit `com.apple.metalperformanceshadersgraph` events from the
     harness process itself: `MPSGraph_Delegate: Delegate init (URL) with resource
     file:///...` + `MPSGraphDelegateKernel.coreAI_prepare caching new IO buffers`
     (6 per run) + `MPSGraph_Init` (AppleInternal build-root string, tempo path).
   - CPU arm (preferredComputeUnitKind=.cpu): ZERO MPSGraph subsystem events; only
     `com.apple.coreai/runtime` ("has been specialized into AIModelCache.default",
     "Loading function 'main'"). Absence of MPSGraph + CoreAI lifecycle = BNNS/CPU
     delegate. Measured matrix in raw/p28_e1_smoke/*_proc.ndjson (33/41/30/8 events).
   - Per-dispatch op signpost stream (paper-style op lifecycle) NOT emitted at
     default level by any arm; anec "Target Architecture" validation events require
     `sudo log config --mode private:on --subsystem com.apple.anec` (user one-shot).

2. PLAN IDENTITY LEAKED BY PUBLIC LOG (unmasked):
   `Delegate init (URL)` prints the full cache plan dir:
   ~/Library/Caches/coreai-cache/26A434/<procname>/<modelHash>/<optsHash>/model.aimodelx/main-this-delegates/<MPSGraph|BNNS>/
   - modelHash stable per model CONTENT (salt file in bundle -> same hash: content-keyed).
   - optsHash stable across MODELS, differs per specialization-options arm
     (deep_fp16 arms: 3EED…/6C51…/1437… for default/neuralEngine/gpu; deep_int8
     neuralEngine reuses 6C51…) -> opts hash keys on options only, not model.
   - proc bucket = consuming process name (p28-run-bin; other sessions' "bench" bucket
     coexists; GPU-arm plans for the same models were already in bench/ from EXP-026).
