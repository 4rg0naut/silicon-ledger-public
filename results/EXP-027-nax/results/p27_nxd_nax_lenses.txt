FINDINGS
 1. PS13 is NOT matmul2d-exclusive. AGX.Count_UT_Engagement_Perf_State_13
    idle=0 -> load=125,798 under PLAIN MSL simdgroup dispatch. NX-C correctly
    showed PS13 counts under matmul2d and idle=0 elsewhere; NX-D shows any
    high-rate small-kernel GPU stream at VMAX engagement drives it. Semantics:
    "UT engaged while GPU in top perf state 13" = saturated-GPU-compute lens.
    It remains disjoint from ANE (AN-POS: PS13=0 during full-ANE reranker run),
    so PS13 stays a valid GPU-vs-ANE discriminator, but cannot separate
    matmul2d (NAX) from simdgroup (classic tensor) work.
 2. Per-unit NAX counter: STILL NONE at user level (gate stamp). Best proxy =
    matched-A/B Δ on `GPU Energy` nJ (idle 2.7 J -> load 150.5 J, 55.3x here).
 3. Secondary NAX-reactive lanes worth adding to enginemon GPU view:
    PMP0 AGX Mem Latency (5,961 -> 132,258), PMP0 AGX #Mem Trans /
    Energy|AGX / DCS BW AGX RD+WR / AF BW AGX RD+WR (10,009 -> 132,754),
    GPU Boost Controller BSTGPUPH (12.0x). AGX.Floor/BW floor channels are
    wall-clock, not load — do not use as lenses.
